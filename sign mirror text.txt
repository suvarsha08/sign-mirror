Create a complete beginner-friendly Python project called “SIGNMIRROR – AI-Powered Visual Communication System”.

PROJECT GOAL:
Build a smart mirror/webcam application that recognizes selected sign-language hand gestures using a webcam and displays the corresponding meaning as text. It should also convert the recognized text into speech.

TECHNOLOGIES:
- Python
- OpenCV
- MediaPipe for hand/gesture detection
- A simple machine-learning or rule-based gesture recognition system
- Text-to-speech using pyttsx3
- Tkinter or a simple OpenCV interface for the display

WORKFLOW:
Sign gesture → Webcam → Hand detection → Gesture recognition → Text → Voice

REQUIRED FEATURES:
1. Open the computer webcam.
2. Detect a person's hand in real time.
3. Track hand landmarks.
4. Recognize a small set of predefined gestures.
5. Start with these sample gestures:
   - HELLO
   - YES
   - NO
   - OK
   - THANK YOU
6. Display the recognized word clearly on the screen.
7. Speak the recognized word using text-to-speech.
8. Prevent the same word from being spoken repeatedly every frame. Add a short cooldown.
9. Show a simple status such as:
   “Show a sign”
   “Recognizing...”
   “Detected: HELLO”
10. Include a clean, attractive “smart mirror” style interface.

USER INTERFACE:
- Title: SIGNMIRROR

- Large webcam preview
